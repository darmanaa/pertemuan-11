# Shop Catalog App

## Deskripsi Aplikasi

Shop Catalog App adalah aplikasi mobile yang dibuat menggunakan React Native dan Expo. Aplikasi ini menampilkan daftar produk dari REST API sehingga pengguna dapat melihat informasi produk seperti gambar, nama, harga, dan kategori.

## API yang Digunakan

* Fake Store API
* https://fakestoreapi.com/products

## Fitur Aplikasi

### Level 1

* Menampilkan daftar produk dari API
* Menampilkan gambar, nama, harga, dan kategori produk
* Loading indicator saat data dimuat
* Error handling ketika koneksi gagal

### Level 2

* ✅ Search Product
* ✅ Pull to Refresh

> Sesuaikan bagian Level 2 dengan fitur yang benar-benar Anda buat. Jika bukan Search dan Pull to Refresh, ganti dengan fitur yang Anda implementasikan.

## Cara Menjalankan Project

1. Clone repository

```bash
git clone https://github.com/darmanaa/pertemuan-11.git
```

2. Masuk ke folder project

```bash
cd shop-catalog
```

3. Install dependency

```bash
npm install
```

4. Jalankan aplikasi

```bash
npx expo start
```

5. Scan QR Code menggunakan aplikasi Expo Go.
